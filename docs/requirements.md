# 📄 リアルタイム翻訳・字幕システム 統合仕様書

## 🎯 目的

配信者（ストリーマー）向けに、音声認識結果およびチャットコメントをリアルタイムで翻訳し、OBS 上に字幕として表示するアプリケーションの構築。
ローカル完結・クラウド・ハイブリッド運用のすべてに対応しつつ、**Electron Forge + Vite + React** によるモダンな構成で「リッチなゲーミング UI」と「高いメンテナンス性」を提供する。

---

## 🛠 I. バックエンド (Node.js/TypeScript & WebGPU) 仕様

| カテゴリ                  | 機能名                     | 技術/ライブラリ                                                                                                      | 詳細仕様                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| :------------------------ | :------------------------- | :------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **A. 音声認識 (ASR)**     | **リアルタイム音声認識**   | `AsrService` (`nodejs-whisper` / `sherpa-onnx-node` SenseVoice-Small / Groq / OpenAI)                                | 1. **VAD (無音検知):** `@ricky0123/vad-web` で発話区間のみを検出し、無駄な推論を抑制。<br>2. **プロバイダー:** ローカル (`whisper-server.exe` / `SenseVoice-Small`) またはクラウド (`Groq` / `OpenAI`) を選択可能。<br>3. **自動フォールバック:** Groq Whisper で HTTP 429 が発生した際、ローカル `SenseVoice-Small` へ自動切り替え（指数バックオフ＆セッション固定）。                                                                     |
| **B. 翻訳 (LLM)**         | **マルチプロバイダー翻訳** | **Groq API** / **OpenAI API Protocol** (OpenAI, Ollama, LM Studio, vLLM) / **PLaMo Local WebGPU** (`@wllama/wllama`) | 1. **2層分離:** LLM トランスポート層（`TranslationService`, `WllamaEngine`）とモデルファミリーアダプター層（`ModelAdapter.ts`）を厳格に分離。<br>2. **ローカルWebGPU & フォールバック:** `plamo-3-translate-0.8b` / `2b` のオンデバイス翻訳に対応し、Groq 429 時は `PLaMo 0.8B` へ自動フォールバック。<br>3. **ストリーミング表示:** `translation.streamingDisplay` により、生成途中テキストをメイン UI および OBS オーバーレイへ逐次配信。 |
| **C. 用語集・プロンプト** | **用語集解決・文脈保持**   | `GlossaryResolver` / `TsvGlossaryPack` / `PromptFactory`                                                             | 1. **用語集:** ユーザー登録辞書（優先度順）および多言語 TSV/ZIP パック（`pos\tja\ten\tko\tzh`）から発話に一致する語彙を注入。<br>2. **会話履歴:** 直近最大 6 ターン（TTL 2 分）の文脈を保持。                                                                                                                                                                                                                                               |
| **D. 外部連携**           | **オーバーレイ配信**       | **Express + Socket.IO**                                                                                              | 1. 翻訳途中（pending）・確定結果をリアルタイムでオーバーレイページへ配信。<br>2. OBS のブラウザソースや通常のウェブブラウザからアクセス可能。                                                                                                                                                                                                                                                                                               |
| **E. ログ出力**           | **開発・運用ログ**         | `electron-log` (`logs/session_*.log`)                                                                                | 1. **出力形式:** 処理結果（ASR、翻訳、フォールバック状態）およびエラーをセッション単位のログファイルへ書き出す。                                                                                                                                                                                                                                                                                                                            |

## 🖥 II. フロントエンド (Electron / UI) 仕様

### 1. 技術選定とインターフェース

| 項目         | 技術/方式                                    | 詳細仕様                                                                                                                                                                                                                 |
| :----------- | :------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **技術選定** | **Electron Forge** + **Vite** + **React 19** | 高速な開発サイクル (HMR) とリアクティブな UI 構築を実現。                                                                                                                                                                |
| **デザイン** | **Tailwind CSS v4** + **DaisyUI v5**         | CSS ファースト構成とゲーマー向けのダークテーマ UI を効率的に構築する。                                                                                                                                                   |
| **通信 IF**  | **IPC** (Inter-Process Communication)        | 1. **基本:** Electron 標準の **IPC**（`preload.ts` 経由）を使用し、低遅延で双方向の通信を実現。<br>2. **PLaMo Local 連携:** メインプロセスから `plamo-translate-request` / `chunk` / `result` 経由で WebGPU 推論を中継。 |

### 2. UI 機能一覧

| カテゴリ          | 機能名                      | 詳細                                                                                                                                                                                                                                                                                                                                                                 |
| :---------------- | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A. 設定 UI**    | **API・モデル・用語集設定** | 1. **Whisper タブ:** `Local` / `SenseVoice-Small` / `Groq` / `OpenAI` と 429 フォールバック設定。<br>2. **LLM タブ:** `Groq` / `OpenAI Compatible` / `PLaMo Local`、429 フォールバック、Streaming Display 設定。<br>3. **Glossary タブ:** 用語登録・優先度並び替え、TSV/ZIP パック管理。<br>4. **VAD / Overlay / General タブ:** マイク・VAD感度・字幕スタイル設定。 |
| **B. ステータス** | **リアルタイム状態表示**    | 1. ヘッダー (`AppHeader`) にプロバイダー別の ASR 稼働状態、Overlay 状態、および `SenseVoice Standby` / `PLaMo Standby` バッジを可視化。                                                                                                                                                                                                                              |
| **C. ログビュー** | **メインログ & 逐次表示**   | 1. `LogViewer` で音声入力・システムログ・翻訳結果（ストリーミング中テキスト含む）をリアルタイム表示。                                                                                                                                                                                                                                                                |

## 🔗 III. アーキテクチャ原則

| 対象                         | 設計原則                                                                                           | 実装モジュール                                                                      |
| :--------------------------- | :------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------- |
| **Transport vs Adapter**     | プロンプト整形・出力クリーニングは `ModelAdapter` に集約し、Transport 層を純粋な実行パイプに保つ。 | `src/services/adapters/ModelAdapter.ts`, `WllamaEngine.ts`, `TranslationService.ts` |
| **レート制限フォールバック** | Groq 429 時の指数バックオフ・セッション固定ロジックを ASR / LLM で共有する。                       | `src/utils/RateLimitFallback.ts` (`AsrService.ts`, `TranslationService.ts`)         |
